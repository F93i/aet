لوحة التحكم

اربط اللوحة بمستودع GitHub الخاص بالموقع لتحفظ التعديلات مباشرة.

كيف أحصل على رمز الوصول؟
  1. GitHub ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens.
  2. اختر المستودع فقط (Only select repositories).
  3. في Permissions ← Repository permissions اجعل Contents = Read and write.
  4. انسخ الرمز والصقه هنا. لا تشاركه مع أحد.
